# C++ OOP Lab 4

C++ object-oriented programming lab: a `person` class showing encapsulation (private/protected/public members), constructors, destructors and inheritance.

## Build

Open `lab4.cbp` in Code::Blocks, or:

```bash
g++ main.cpp -o lab4
./lab4
```
